# Experimental controls

Every experiment should specify:

- fixed variables
- manipulated variable
- observable
- null hypothesis
- positive/negative control
- number of initial states
- number of rules
- random seeds
- stopping condition
- reproducibility level
- exact code version

Core control principle:

If two structures are compared, first determine which properties are equal.
Do not attribute an observed effect to triangles, hubs or crystallinity when
degree, size, connectivity or another uncontrolled property changed at the
same time.
