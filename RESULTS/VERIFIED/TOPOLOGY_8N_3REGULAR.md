# Verified result: topology and dynamics

Model: N=8 binary nodes, degree=3, synchronous update rule f(self, active_neighbor_count). There are 256 local rules and 256 initial states per rule.

Six non-isomorphic 3-regular graphs on 8 vertices were enumerated.

Verified observation: changing topology while keeping node count, edge count, degree and local-rule family fixed changes attractor, basin and cycle statistics.

Important control: two connected graphs can share N=8, E=12, zero triangles and lambda_2=2 while still showing different cycle statistics.

Interpretation: topology is a meaningful constraint on dynamics in this model. This is not a universal law claim.
