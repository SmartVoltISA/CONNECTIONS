# Metrics

## Topology
- node count N
- edge count E
- degree sequence
- triangles
- clustering coefficient
- connected components
- diameter
- average path length
- Laplacian spectrum
- algebraic connectivity lambda_2
- adjacency spectrum

## Dynamics
- number of attractors
- basin sizes
- basin entropy
- transient length
- cycle length
- maximum cycle length
- sensitivity to one-bit perturbation
- sensitivity to one-edge rewiring

## Structure
- motif counts
- local clustering
- community/modularity descriptors
- hub concentration
- spatial/order parameters for lattice-like structures
- persistence under perturbation

A single scalar metric must not be treated as a complete description of a
graph or its dynamics.
