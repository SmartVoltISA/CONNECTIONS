# Hidden-state / memory experiment

Model: observed binary state S plus hidden bit M, giving four internal
configurations and 256 deterministic transition systems.

Observed result:
- 192/256 systems (75%) allow the same observed state to lead to different
  observed next states depending on hidden state.
- 80/256 systems (31.25%) show different long-term stable regimes from the
  same observed state under different hidden states.

Interpretation:
Historical dependence can arise from hidden state.

Important control:
Hidden state can always be re-described as part of an expanded state.
Therefore this experiment does not prove that "memory" is a fundamental
primitive; it demonstrates an operational effect of unobserved state.
