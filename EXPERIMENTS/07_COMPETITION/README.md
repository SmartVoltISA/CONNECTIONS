# Resource competition

Earlier models tested multiple agents competing for a limited resource.

Critical control finding:

A single limited resource with simultaneous requests requires a conflict
resolution rule. A fixed priority/min/max rule injects asymmetry. A symmetric
tie rule such as "nobody wins" does not spontaneously select a winner.

Therefore claims that competition alone necessarily creates a boundary or
winner were rejected as too strong.

Status: methodological result / control requirement.
