# Emergent structure

This branch asks a stronger question:

Can a structure such as a triangle, hub, crystal/lattice pattern or module
appear from local interaction rules without specifying the final structure?

Required protocol:

1. Define the local rule before the run.
2. Define the initial graph/state distribution.
3. Define measurable structural signatures.
4. Include negative controls.
5. Record every parameter.
6. Separate spontaneous formation from structures already present in the initial condition.
7. Repeat across random seeds where randomness exists.

No structure should be declared "emergent" merely because it is visible.
It must be absent or statistically distinguishable in the null control and
appear under the tested dynamics.
